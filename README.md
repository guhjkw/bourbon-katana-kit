# Katana Move Kit

A working tool for Bourbon Royalty's move from SOS Inventory to Katana. Drop in the exports Bourbon Royalty already has (the SOS item list, the SOS assemblies, and the Faire or MarketTime orders). It returns:

- **Product codes:** every code problem to fix before importing: the same code on two items, codes that differ only in capitals or spaces (SB-1OIL in SOS, SB-1Oil on Faire), blanks, typos on orders with the closest real code, assemblies with no recipe, recipes using unknown items, archived items still ordered, materials with no cost
- **Katana files:** materials, products and recipes ready to import, on the codes Faire and MarketTime send (or clean capitals, with the listings to change). Drop in Katana's own blank templates and they are filled column by column in Katana's order
- **Order desk:** every open order line checked: unknown code, price different from SOS, archived item, late or shipping this week, no ship-by date, duplicate line, zero quantity
- **Make plan:** what each line (wax, laundry, misc, mop) makes for the orders in the next 7, 14 or 30 days, topped up to reorder points, and the materials to buy with suppliers and cost
- **Cutover plan:** dated steps to go-live, skipping weekends and US holidays

Everything runs in the browser. Files are read on the computer they are dropped on and never uploaded; nothing in SOS, QuickBooks, Faire or Katana is changed.

## Try it

Open `index.html` (double-click works) and press **Try it with sample files**, or drop in real exports. Excel (.xlsx) and CSV both work. Columns are found by name and every one can be re-pointed under "Check or change". A file dropped in the wrong box is named for what it is.

The sample files in `samples/` are invented (items, retailers, stock and prices) and contain one of every problem the kit looks for.

## How it decides

| Question | Rule |
|---|---|
| Same item? | Codes are compared trimmed, capitals ignored, spaces/underscores/slashes as hyphens. Katana itself matches exactly, so any difference is reported |
| Code in Katana | The spelling the orders use (most common one), so Syncware matches without editing listings. "Clean capitals" instead upper-cases every code and lists the listings to change |
| Product or material | Product: an assembly in SOS, anything with a recipe, anything on an order, or anything with a price that is not an ingredient. Material: the rest. Services and archived items nobody orders are left out |
| Make or Buy | Make when it has a recipe, Buy otherwise |
| Make quantity | Ordered (lines shipping within the window, or with no ship-by date) plus reorder point, minus on hand, rounded up |
| Materials | Make quantities through every level of the recipe, plus reorder point, minus on hand |

## Files

```
index.html             the page (loads the three scripts below with plain script tags)
src/tablekit.js        reads CSV and .xlsx, finds columns by name, reads money and dates, writes .xlsx and .csv
src/katanaKit.js       the audit, Katana files, order desk, make plan and cutover plan
src/samples.js         the sample files for the "Try it" button (generated by build.py from samples/)
samples/*.csv          invented sample exports
tests/verify.js        node tests (same src files as the page)
tests/browser-check.py drives the real page in Chromium
tests/make-fixtures.py writes a real Excel SOS export and a stand-in Katana template for the tests
```

## What the connected version adds

This kit works on exports. Connected to Bourbon Royalty's Katana, Syncware and QuickBooks, the move is carried out (imports, Syncware pointed at Katana, invoices on pack, a parallel week), and the order desk, make plan and purchase orders run on their own inside Katana. That part uses Bourbon Royalty's own accounts.

Katana column names follow Katana's help-centre articles on importing products, materials and recipes (read 27 Oct 2026). Katana's own blank templates are the authority; drop them in to fill them exactly.
